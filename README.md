A chess engine in at most 4,096 bytes of Python: negamax alpha-beta with a transposition table, quiescence search, null-move pruning and late-move reductions, searching a fixed node budget so every move is deterministic. It plays through the make.fun env protocol.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
